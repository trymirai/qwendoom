Movement, enemies and weapons run through a RISC-V CPU compiled into Qwen weights. A numerical CPU: nobody trained this model, a compiler computed every weight of a stock Qwen3.5 checkpoint. Its Gated DeltaNet state holds the RAM, the level and the program, and every game tick runs as RV32 machine code that the model predicts one token at a time, while the host only draws the frames and feeds your keys in as tokens. A tick takes about 23,000 tokens, and one Apple silicon CPU core runs about 30,000 a second: about a frame a second. Built on Qwenputer’s compiler and inspired by nesformer; game data from Freedoom.
